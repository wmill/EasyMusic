# Easy Music

So the idea behind this is that I've found existing music learning apps to be too tied up in the physicality of the instrument. 

Usually music apps just present a piano-esque layout. The plan is to start with keys for a 12 semitone octave, teach them keys by rote, teach them chords by rote, and after many years they will learn about music theory. 

The idea here is to have the user pick a key, then just present the seven notes in the key in three octaves. 

That way chords are obvious. They can jam with a group without having to worry about hitting a wrong note. 

Obviously trying to play more complex songs is a problem, but we can get a group having fun right away. Jamming to a click track.
